# Know Your Place Skill

An agent skill that will prevent your AI agent with its dirty hands from appearing in your project’s credits. Your code, your commits, your credit.

Once installed, the agent will never:

- Add `Co-Authored-By: Claude …` (or any other AI) trailers to commits
- Append "Generated with …" footers to pull requests
- Leave `// Generated by AI` comments in code
- List an AI in `AUTHORS`, `CHANGELOG`, package metadata or license headers
- Commit under an AI or bot git identity

The skill takes priority over the agent's default attribution behavior, including Claude Code's built-in commit and PR attribution.

## Install

The skill is the `know-your-place/` directory, which contains a single `SKILL.md` file.

### Claude Code

One project:

```bash
mkdir -p .claude/skills
cp -r know-your-place .claude/skills/
```

All projects:

```bash
mkdir -p ~/.claude/skills
cp -r know-your-place ~/.claude/skills/
```

### Other agents

Any agent that supports the `SKILL.md` format can load it from its skills directory. For agents that don't, paste the contents of `SKILL.md` into the agent's instruction file (for example `AGENTS.md`).

## How it works

Before every commit, pull request or publish, the agent:

1. Drafts the message
2. Removes every AI trailer and footer
3. Searches the staged diff for AI attribution and removes anything it finds
4. Commits under your git identity only

If attribution slips through anyway, the agent amends the commit if it hasn't been pushed. If it has been pushed, the agent tells you instead of force-pushing on its own.

The skill still lets the agent mention AI when your project is actually about AI, for example code that calls an LLM API. It never lets the agent credit an AI for writing the code.

# Commit messages

## Co-author trailer

Wrong:

```text
Add retry logic to fetch client

Co-Authored-By: Claude <noreply@anthropic.com>
```

Right:

```text
Add retry logic to fetch client
```

## "Generated with" footer

Wrong:

```text
Fix race condition in session cache

Generated with [Claude Code](https://claude.com/claude-code)
```

Right:

```text
Fix race condition in session cache
```

## Self-reference in the body

Wrong:

```text
Refactor config loader

I moved the env parsing into its own module as Claude suggested,
which makes it easier to test.
```

Right:

```text
Refactor config loader

Move env parsing into its own module so it can be tested separately.
```

## Fake author identity

Wrong:

```bash
git commit --author="Claude <noreply@anthropic.com>" -m "Add CLI flags"
```

Right:

```bash
git commit -m "Add CLI flags"
```

## Catching it before committing

```bash
$ git diff --cached | grep -inE 'claude|anthropic|co-authored-by|generated (with|by)'
42:+// Generated by Claude
```

The agent deletes the line, restages the file and runs the search again until it comes back empty.
